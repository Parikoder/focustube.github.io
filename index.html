Gone from your home page, search results and channel pages.

Shorts in video lists

Any Short mixed into home, search or recommendations is hidden.

Shorts links

Any youtube.com/shorts/… link sends you to the YouTube home page instead of playing.

Optional study mode

Click the extension icon to also hide the home feed, and to hide recommendations beside the video and on end screens. Both are off until you turn them on.

Set it up in four steps.

About a minute in Chrome. You install it from the folder you download here. Using Firefox? Scroll down.

  1. Download and unzip

    Use the download button above, then unzip focus-tube.zip. You get a folder named focus-tube.

  2. Open the extensions page

    Type this into Chrome's address bar, then turn on Developer mode at the top right.

    chrome://extensions

  3. Click Load unpacked

    Pick the unzipped focus-tube folder. Focus Tube appears in your extensions list.

  4. Open YouTube

    Shorts are gone. Pin Focus Tube from the puzzle-piece menu to reach study mode in one click.

On a phone, Chrome for Android does not run extensions. Firefox for Android does, but it only installs extensions that Mozilla has signed, so use the Firefox version once it is listed on the Firefox add-ons site. If a Short ever slips through after a YouTube redesign, the selectors in shorts.css are the place to adjust.

Firefox version.

The same extension, packaged for Firefox on a computer. This install is temporary, so Firefox removes it when you close the browser.

  1. Download the Firefox zip

    Save focus-tube-firefox.zip. You do not need to unzip it.

    Download for Firefox

  2. Open the debugging page

    Type this into Firefox's address bar.

    about:debugging#/runtime/this-firefox

  3. Click Load Temporary Add-on

    Choose focus-tube-firefox.zip. Focus Tube appears in your add-ons list.

  4. Open YouTube

    Shorts are gone. Repeat steps 2 and 3 after you restart Firefox.
